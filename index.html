سياسة الخصوصية لتطبيق eSCHOOL

آخر تحديث: نوفمبر 2026 — مقدم الخدمة: شركة تيم ون (Team One)

تحترم شركة تيم ون خصوصية الطلاب وأولياء الأمور والهيئات التعليمية والإدارية عند استخدام تطبيق eSCHOOL. توضح هذه الوثيقة أنواع البيانات التي يتم معالجتها وكيفية استخدامها وحمايتها.

1. البيانات التي نجمعها أو نعالجها

  • بيانات الحساب والملف المدرسي: مثل الاسم، المعرّف الدراسي، المدرسة، المرحلة/الصف، والشعبة لتقديم الخدمات المدرسية المخصصة.
  • البيانات الأكاديمية والتشغيلية: مثل سجل الحضور والغياب والإجازات، الكتب الدراسية، الواجبات المدرسية وحالة تسليمها، والبيانات المالية الدراسية المرتبطة بحساب الطالب.
  • معرّفات الجهاز والإشعارات: مثل رموز الإشعارات (FCM Tokens) لإرسال التنبيهات المدرسية والواجبات والمواعيد المهمة.
  • البيانات التشخيصية: سجلات الأخطاء والأداء لتحسين استقرار التطبيق ومعالجة الأعطال.

2. كيفية استخدام البيانات

  • تشغيل ميزات النظام المدرسي وعرض الجداول والواجبات والحضور والحسابات وفق صلاحيات المستخدم.
  • إرسال الإشعارات والتنبيهات المتعلقة بالدراسة والواجبات.
  • تحسين جودة الخدمة، أمان الجلسات، ومنع إساءة الاستخدام.

3. مشاركة البيانات والخدمات الطرفية

لا نقوم ببيع بيانات المستخدمين لأي جهة خارجية. قد تتم معالجة أو تخزين بعض البيانات عبر مزودي بنية تحتية سحابية موثوقين (مثل خدمات Firebase والاستضافة السحابية) وفق الضوابط الأمنية اللازمة، وبما يقتصر على تشغيل المنصة التعليمية للمدرسة المعنية.

4. حماية البيانات والاحتفاظ بها

نطبّق إجراءات تقنية وتنظيمية مناسبة لحماية البيانات من الوصول غير المصرح به أو التعديل أو الفقدان، وتُحتفظ بالبيانات طالما كان الحساب أو التعاقد المدرسي نشطاً أو حسب المتطلبات الإدارية المعتمدة.

5. حقوق المستخدم وطلبات الحذف أو التعديل

يمكن للمستخدمين أو الجهات الإدارية المخولة طلب مراجعة أو تحديث أو حذف البيانات المرتبطة بالحساب وفق السياسات المعتمدة للمدرسة عبر التواصل معنا.

6. التواصل معنا

لأي استفسار حول سياسة الخصوصية أو طلبات البيانات، يرجى التواصل عبر البريد الإلكتروني الرسمي: support@teamoneco.com
